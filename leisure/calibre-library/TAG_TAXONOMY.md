# Calibre Library Tag Taxonomy

Library: `/home/mcooney/Calibre Library` (263 books, 138 distinct tags as of
2026-07-06)

This is the **source of truth** for tags going forward. When adding a new
book:

1. Check this list first. If an existing tag matches the book's genre or
   subject, use it — do not invent a near-duplicate variant (e.g. don't add
   `Sci Fi` when `Science Fiction` already exists; don't add `WWII` when
   `World War II` already exists).
2. If no existing tag genuinely fits, add a new **canonical** entry here
   under the appropriate category, then apply it to the book — not a
   one-off tag that only lives on that one book's metadata.
3. Do not resurrect any tag listed in `NORMALIZATION_LOG.md` under "Tag
   merges applied" or "Deletions" — those were deliberately retired.

Some tag pairs look redundant but are intentionally distinct (e.g.
`Historical` vs `Historical Fiction`, `Football` vs `Sports`, `Money` vs
`Finance`, general vs geography-scoped LOC headings like `Rare books` vs
`Rare books - Spain - Barcelona`). See `NORMALIZATION_LOG.md` for why these
were left alone — do not merge them without re-reading that reasoning.
