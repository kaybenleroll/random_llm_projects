## Legend

- ID: A- = per-tier prompting pages, B- = best-practices, effort, what's-new, migration guides and system cards, C- = Claude Code docs, D- = the `prompt-audit.md` and `model-migration.md` files of the `claude-api` skill in the anthropics/skills GitHub repo (Anthropic-published skill text, pinned to commit 9d63080, not documentation pages; added later, so D IDs run D-01 to D-129 and merged ones appear only under Merged duplicates). Original IDs kept.
- claim: short paraphrase. verbatim quote: exact text from the snapshot (at most 30 words).
- snapshot file + section: file in `sources/` plus heading.
- Stated/Opinion: Stated = the source says it; Opinion = inference from a Stated quote.
- Opus / Sonnet / Haiku / Fable: `applies`, `n/a`, `silent` (source says nothing for that tier) or `differs: ...` (source states something tier-specific). Mythos is treated as Fable.
- applies-to-CC-prompt-files: yes/no/n/a, whether it bears on CLAUDE.md, skills, agents, hooks and similar prompt files.
- new-in-5.x: yes/no/n/a, whether the point is new in a 5.x model.
